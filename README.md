# 習慣トラッカー

## 概要

毎日続けたい習慣を登録し、達成した日をチェックしていく習慣トラッカーです。
習慣ごとに当月のカレンダーで達成状況をひと目で確認でき、連続達成日数や達成率も自動で計算します。
記録はブラウザのlocalStorageに保存されるため、ページを再読み込みしても消えません。

## 機能

- 習慣の追加（Enterキーでも追加可能）・削除（確認ダイアログあり。削除すると記録も消える）
- 「今日をチェック」ボタンで今日の達成を記録 / 取り消し
- 習慣ごとに当月のカレンダーグリッドを表示し、達成した日を色付けで表示
  - 過去の日付もマスをタップして記録・取り消しが可能（未来の日付は不可）
- 習慣ごとの統計
  - 連続達成日数（🔥ストリーク。今日が未チェックでも昨日まで続いていれば継続扱い）
  - 週（直近7日）・月（今月1日〜今日）の達成率
- 全体の統計
  - 今日の達成数（達成数 / 習慣数）
  - 全習慣の平均達成率（今週 / 今月 / 直近30日）
- localStorageによるデータ永続化
- モバイル対応のレスポンシブデザイン

## 使用技術

- HTML
- CSS（カスタムプロパティ / CSS Grid / メディアクエリ）
- JavaScript（フレームワーク不使用のバニラJS）
- localStorage（日付は `YYYY-MM-DD` 文字列で管理）
- デプロイ: Cloudflare Pages
